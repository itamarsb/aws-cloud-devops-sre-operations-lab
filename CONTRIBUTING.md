

# Contributing

This repository is primarily an engineering laboratory and professional portfolio project.

Contributions, suggestions and technical discussions are welcome.

## Development Principles

Changes should:

- Follow clear Git commit practices
- Avoid exposing credentials
- Include relevant documentation
- Prefer reproducible infrastructure
- Follow security best practices
- Keep configurations readable
- Include validation steps whenever possible

## Commit Examples

```text
docs: add Stage 00 workstation guide
feat: add AWS VPC Terraform module
fix: correct security group rule
ci: add GitHub Actions validation workflow
monitoring: add Zabbix host template
observability: add Datadog dashboard configuration
incident: document INC-001 application outage
finops: add EC2 rightsizing analysis
```
