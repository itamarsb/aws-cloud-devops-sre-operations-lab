# aws-cloud-devops-sre-operations-lab

End-to-end hands-on lab for Cloud, DevOps, SRE and Observability on AWS. Includes Terraform, Docker, Kubernetes, CI/CD, GitHub Actions, Python, Bash, Zabbix, Datadog, Incident Management, Troubleshooting, IAM/Security, Networking and FinOps.
